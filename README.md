# 航空物流塔 / Air Logistics Tower

[English](README.en.md) | **简体中文**

Factorio 模组：航空与星际物流塔。用飞机与飞船在同一星球、不同星球之间取送货物与流体，塔内提供数字分区仓储、原版物流与建设机器人平台，以及自动采矿。

当前版本 **0.12.71** ｜ 更新日志：[CHANGELOG.md](CHANGELOG.md)

## 功能

- **数字分区仓储**：每座塔有 5 个货物分区（星际塔为 9 个规则位），以图标与数字显示。点击图标可直接取放货物、设置需求数量或供给下限。
- **机器人平台**：需求分区通过物流机器人从物流箱取货；供货与仓储分区供物流与建设机器人取用。
- **飞机双向取送**：飞机可在同一星球的两类塔之间双向取送，按优先级、轮流服务与严格满载规则派机。
- **星际运输**：星际塔的机库同时接受飞机和飞船，飞船执行跨星球货物与流体运输。
- **智能带口**：传送带接口按前方的物料自动识别输入，或按筛选键输出，并可与红绿线联动。
- **自动采矿**：采集相连矿脉、喷泉，以及塔体覆盖的海洋流体，自动配置空闲供应分区。
- **共享无限科技**：容量、速度、载货、机群等无限科技，等级对同一阵营共享。

## 兼容性

- Factorio **2.1.21** 及以上；另有 2.0 稳定版构建（见上表）。
- 界面内置**简体中文**与**英文**。
- 在 Factorio 2.0 上，物流塔窗口中「由脚本绑定的物品格子」无法显示（该界面元素为 2.1 新增），其余按钮、数字、筛选与信息保持可用。
- 物品、建筑与科技的内部名称保持不变，升级后可直接沿用旧存档。

## 安装

1. 下载 [release](release/) 目录中的最新发布包，例如 `air-logistics-tower_0.12.71.zip`。
2. 将 zip **原样**放入 Factorio 的 `mods` 目录，不要解压。
   - Windows：`%APPDATA%\Factorio\mods`
   - Linux：`~/.factorio/mods`
   - macOS：`~/Library/Application Support/factorio/mods`
3. 启动游戏，在「模组」列表中启用，然后重新启动游戏。

也可以在游戏内的模组门户搜索「航空物流塔」安装。
